## Screens

| Route | Purpose |
|-------|---------|
| `/` | Home — category cards, Book Now |
| `/services/lashes-brows` | Lash & brow price list |
| `/services/nails` | Nail price list |
| `/book` | Multi-step booking (live Supabase) |
| `/book/confirm/[id]` | Booking confirmation |
| `/calendar` | Schedule overview |
| `/admin/login` | Owner login |
| `/admin` | Owner calendar (auth required) |

## Stack

- Next.js + TypeScript + Tailwind
- Supabase (appointments, services, auth)
- Playwright E2E tests
- Vercel + PWA
